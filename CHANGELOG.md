# Changelog

## 3.0.0 (2026-10-08)

### Ключевые изменения

- **Полный отказ от `cscart_pages`.** Модуль больше не использует страницы ядра CS-Cart
  (`page_type = 'M'`) как хранилище. При установке данные старых страниц производителей
  мигрируют в независимые таблицы, после чего страницы удаляются.
- **Независимые таблицы номенклатуры:**
  - `cscart_nomenclature_nodes` — дерево узлов (производитель `M` / категория `C` / группа товаров `G`);
  - `cscart_nomenclature_node_descriptions` — мультиязычные названия и описания;
  - `cscart_nomenclature_links` — связь many-to-many `product_id` → `node_id`.
- **Новый бэкенд** — контроллер `nomenclature.*` (`manage`, `update`, `add`, `delete`,
  `multi_delete`, `update_status`, `picker`) с собственными шаблонами `manage.tpl` / `update.tpl`
  (поля: название, описание, ЧПУ, изображение, вкладка привязки товаров).
- **Независимый пункт меню** `nomenclature.manage` вместо перехвата `pages.manage`.
- **Динамическая генерация характеристик товаров из `features`** — таблица на странице группы
  строится из штатных характеристик CS-Cart и цен; статичный JSON параметров удалён.
- **Информационно-справочная таблица товаров** — артикул, параметры, цена, наличие.
  Функционал «В корзину» и покупки из таблицы убран.
- **Изображения** — стандартный механизм CS-Cart: привязка `images_links` с типом объекта
  `nomenclature_main`.
- **SEO** — аддон регистрирует объект `nomenclature` (dispatch `nomenclature.view`),
  ЧПУ-имена мигрируют из старых `pages.view` при установке.
- **Фронтенд** — страница `nomenclature.view`, сохранены плитки и сетка каталога
  для тем `responsive` и `abt__unitheme2`.

### Технические детали

- Версия ядра: CS-Cart 4.18.x (ULTIMATE / MULTIVENDOR).
- Миграция идемпотентна: повторная установка не дублирует данные.
- Удаление узла рекурсивно удаляет дочерние, связи с товарами и изображения.

## 2.3.3 (2026-10-06)

- Исправлено сохранение родительской страницы (`parent_id`) при создании.
- Корректный тип элемента (`manufacturer_elem_type`) для корневых и вложенных страниц.
- Активный пункт меню «Производители» при работе со страницами.
